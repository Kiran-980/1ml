# What this plugin supplies

The twelve skills are separately invocable agent workflows. They select methods, write task-specific analysis code when appropriate, run available tools within authorization, interpret measured outputs, and preserve notebook/state evidence. They are not twelve prebuilt model-training engines.

## Included local machinery

- Data profiling for ordinary CSV/TSV, SQLite and compatible Parquet environments; inspect resource limitations before reading large sources.
- Project-local state, declared task prerequisites, completion/outcome distinctions, migration, revision checking and stale propagation.
- Validated notebook cell plans, ordered recorded dependencies, conflict detection, atomic writes, and idempotent replay.
- Packaged methodological references and specialist task profiles. Only read the branches relevant to the current claim.

## Task-specific execution

Supervised tabular modeling, statistical calculations and specialized analysis require project-specific code, installed libraries, a valid design, and observed results. Use current official documentation for the installed versions. An estimator appearing in a reference is not proof of a tested adapter. Preserve this distinction when reporting what ran.

Specialist profiles establish framing, assumptions and return routes for forecasting, survival, ranking, causal analysis, anomalies, clustering, scarce labels, media, generative systems and sequential decisions. If a required method/design cannot be justified or executed with the environment, record `needs_research`, the missing prerequisite, and the next useful action. Complex survey, graph/spatial dependence, longitudinal causal identification, federated training, certification and domain-regulated release need targeted expertise/research rather than generic supervised substitution.

## External actions and limits

No preconfigured cloud deployment adapter, automatic production monitor, data-purchase integration, or live experiment launcher is included. Release/operate/experiment can prepare concrete plans and use user-authorized available integrations after verifying their requirements. A skill invocation does not authorize spending, disclosure, participant contact, publication, or live exposure beyond the user's request.

Static link/frontmatter checks and helper tests verify packaging and specific mechanics. They do not prove every agent invocation, scientific conclusion, estimator implementation, or production deployment. Scenario cases in [behavior checks](../tests/scenarios/decision-paths.md) define the expected evidence to assess those behaviors independently.
