Define what “unseen” means

A random row split answers a different question from a test on new customers or a future month. If the same customer appears in training and validation, a strong score may not describe performance on customers the model has never seen.

Use the evaluation skill to define labels, metrics and split boundaries before model selection. Use the validate skill to assess a frozen model and explain its supported claims afterward.

Audit an existing notebook for leakage

Use 1ml's evaluation skill to audit my customer-churn notebook. Customers have multiple monthly rows, and the intended use is predicting churn for new customers in a later period. Inspect the label window, when features become available, entity overlap and chronological boundaries. Check whether preprocessing, tuning or threshold selection uses reserved outcomes. Show evidence for each issue and propose a feasible evaluation design. If the data cannot support the intended claim, explain that limitation rather than relaxing the split to get a score.

Choose metrics that describe the decision

TaskQuestions to resolve
ClassificationDo you need ranking, calibrated probabilities or decisions at a threshold? What do false positives and false negatives cost?
RegressionAre typical absolute errors or large misses more important? Report errors in units the reader can interpret.
ForecastingWhat horizon and forecast origin matter? Compare against seasonal baselines using chronological backtests.
ClusteringAre groups stable and useful? A compactness score alone does not establish a meaningful segmentation.

Separate selection from final evaluation

Choose models, features and decision thresholds using the permitted development evidence. Fit learned preprocessing inside the relevant training folds. Freeze the chosen approach before evaluating the final holdout.

If final-test errors guide another model change, those outcomes have become development evidence. Report that change and establish renewed evaluation rather than calling the same test untouched. Keep undefined metrics and failed predictions visible; silently removing them can change what the score means.

Make the comparison reproducible

A useful evaluation records split identifiers or time cutoffs, target eligibility, baseline and candidate scores, relevant subgroup support and limitations. Repeated or related observations affect how much independent evidence you have. The statistics skill can help assess uncertainty when the design supports it.
