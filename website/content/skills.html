From a question to evidence

ML skills for AI agents.

Twelve machine learning skills for data analysis, feature engineering, training and model evaluation. Use them in Codex or Claude Code to build a notebook or review one decision.

What is a machine learning skill for an AI agent?

An ML skill is a set of instructions and references your coding agent loads for a particular kind of machine learning work. Each 1ml skill has a SKILL.md file that defines its responsibilities and links to deeper guidance. The agent writes and executes project code in your environment; you can inspect every instruction in the agent skills on GitHub.

The lifecycle skill helps route a new or existing project. Individual skills can also answer a focused question without starting an entire project. 1ml supports the work of analyzing data and evaluating models; installing a skill does not train a model by itself.

Choose one ML skill or a whole project

Give the agent the data context and the decision you need to make. These starter requests show when a focused skill is useful:

  • Review a validation split: “Use the evaluation skill to review my churn notebook. Customers appear in several rows, and the model will predict for new customers. Check whether any customer crosses the split.”
  • Investigate missing data: “Use the explore skill to investigate missing sensor readings. Check which devices and periods are affected before recommending an imputation method.”
  • Build a forecasting notebook: “Use the lifecycle skill to forecast the next 14 days of sales. Establish a seasonal baseline, use chronological backtests, and explain which inputs are available at each forecast origin.”

For a complete first run, try the synthetic classification project. For an executed example, read the public text-classification notebook.

The twelve machine learning skills

SkillThe question it owns
lifecycleWhat is the next useful step?
frameIs ML useful for this decision?
dataWhere does the data come from, and what does it mean?
evaluationWhat metric and split support the intended claim?
exploreWhat structure, missingness or anomalies matter?
statisticsWhat can we estimate, and how uncertain is it?
prepareHow should features and preprocessing be constructed?
trainWhich models and tuning budget are justified?
validateWhat does the frozen evaluation actually support?
experimentHow should an intervention or A/B test be designed?
releaseCan someone reproduce and use the supported result?
operateWhat changed, and should the system be repaired or retrained?

Choose the task before the algorithm

Classification predicts categories. Regression predicts numbers. Forecasting predicts future observations, with special information boundaries. Clustering explores groups without known target labels.

Exploratory data analysis, statistics and model evaluation support each of these, but their role depends on the question. An intervention experiment answers a causal question; a predictive test alone does not.

Using these skills in Claude Code and Codex

Install the 1ml plugin, open your project folder, and ask your agent to use the lifecycle skill or a specific owner such as evaluation or train. The Claude Code and Codex installation guide includes the commands and a small project to verify the setup. All twelve skills are free under the MIT license; agent services and compute can have their own costs.

Know what the checks establish

Installation checks show that instructions and references load. Software tests check mechanics. Scientific claims still require an appropriate design and measured evidence. Read the evaluation guide and observed limitations before relying on unattended work.
