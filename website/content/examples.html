Can tweet text identify real disasters?

This public text-classification notebook was made with 1ml for Kaggle's Natural Language Processing with Disaster Tweets problem. The task is to distinguish tweets describing real disasters from those that do not.

Follow how text becomes model features, how a baseline is evaluated and how the notebook explains its findings. One example is not certification across datasets, agent hosts or models.

Start with your own problem

These are guides and starter prompts, not claims of completed experiments:

  • Customer churn classification: define the label and prediction time, choose a split and investigate costly mistakes.
  • House-price regression: compare simple baselines and models, then explain residuals in useful units.
  • Daily-demand forecasting: define a horizon and compare against seasonal baselines with chronological backtests.
  • Customer segmentation: inspect features, test stability and decide whether the groups support a useful interpretation.

Share an example that others can learn from

A useful contribution explains the question, data source, validation design, measured result and limitations. Include dependency versions and the files needed to reproduce the analysis. Use public or appropriately licensed data; keep credentials and personal information out of shared notebooks.

Link to 1ml so readers can try the same skills. You do not need a paid plan or a successful competition score to contribute an instructive example. A carefully explained failure can be just as useful.
