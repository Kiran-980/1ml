Understand the data before modeling

Exploratory data analysis skills for AI agents.

Use 1ml in Claude Code or Codex to investigate missing data, distributions and relationships in a Python notebook. Start with a question the analysis can answer.

Give the investigation a purpose

Exploratory data analysis (EDA) helps you decide what to investigate, collect or change next. For example, a sensor dataset may have many missing readings, but a single missing-value percentage cannot tell you whether devices went offline, measurements were never applicable or records were lost during a join.

The data skill checks sources, units and joins. The explore skill investigates patterns with calculations and relevant charts. Use the statistics skill when you need estimates, uncertainty or an inferential comparison.

Ask about missing sensor readings

Use 1ml's explore skill to analyze missing readings in sensors.csv. Each row is a device measurement at a timestamp. Check units, duplicate device-time pairs and gaps by device and week. Show the distributions and missingness patterns needed to distinguish the plausible explanations. Report the number of observations behind comparisons, separate facts from hypotheses, and explain what additional evidence would resolve uncertainty. Deliver an executed Jupyter notebook with concise findings. Do not impute values until the investigation supports a choice.

Useful charts answer specific questions

  • Missingness over time: does a gap affect one device or an entire collection period?
  • Distributions by source: could different units or collection methods explain apparent outliers?
  • Category counts: are rare groups supported by enough observations to compare?
  • Relationships: does a pattern persist within relevant groups, or depend on how the data was combined?

A correlation plot alone does not show causation. A skewed variable does not automatically need a logarithm. Ask the agent to connect each consequential finding to a decision, including leaving a column unchanged.

Keep predictive exploration within development data

Initial schema and integrity checks can happen before a predictive split. Adaptive exploration that selects features or models should use development data and preserve the final evaluation. A purely descriptive analysis has a different purpose and does not automatically require a prediction holdout.

If the investigation suggests a transformation, continue with feature engineering and preprocessing. If the evidence raises questions about which rows may be compared, review the validation design first.
