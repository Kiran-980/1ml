Predict ahead, without looking ahead

The future belongs outside the training set.

Define the horizon, compare seasonal baselines and backtest the way the forecast will actually be used.

Define the forecast before making features

Specify a time column, observation frequency, target and forecast horizon. A daily forecast made every morning for tomorrow is a different task from a 14-day forecast made once today.

Check missing dates, duplicate timestamps and whether zero demand means the same thing as missing data. For multiple stores or products, explain which series will be known at deployment and which could be new.

A prompt to start with

Use 1ml to forecast daily demand from daily-demand.csv for the next 14 days. Check missing dates and distinguish zero from missing demand. Define the forecast origin, horizon and features available at that origin. Compare a weekly seasonal-naive baseline with a justified forecasting model using chronological backtests. Keep the final period untouched until the approach is frozen. Show forecasts beside actual values and explain errors across periods. Deliver an executed notebook with reproducible dependencies.

Respect the information boundary

  • Chronological evaluation: training observations precede the period being predicted. Repeated forecast origins help assess behavior across periods.
  • Seasonal baseline: compare with an appropriate recent or seasonal reference before adding complexity.
  • Features: distinguish future-known inputs such as a calendar from inputs that arrive only after the forecast.
  • Multi-step forecasts: do not construct future lag features from actual target values that would not yet be available.

Explain variation across time

Report the horizon and error metric alongside results. A single average can hide failures during promotions, peaks or changing regimes. Compare the model and baseline over the same windows and inspect their error patterns.

Useful output: a clear origin-and-horizon definition, forecasts plotted against actual values, a baseline comparison across backtest windows and an explanation of forecast limits.
