Install 1ml

1ml is free and open source under MIT. There is no 1ml subscription or account. Your agent, model provider and compute may have their own costs.

Claude Code

Run these commands inside Claude Code:

$claude_install

Codex

Run in a terminal with a Codex CLI version that supports plugins:

$codex_install

Start a fresh session and select 1ml:lifecycle in the skill picker, or ask the agent to use it. Open a working folder outside the plugin checkout.

The complete installation guide covers verification, automatic updates, local alternatives, OpenCode, Gemini CLI, Pi and Hermes. Native installation and discovery were verified in Codex and Claude Code; the other routes are documented, not end-to-end certified. Keep the whole repository together so linked references resolve.

Try a small classification project

No dataset ready? Use synthetic data to try the workflow before connecting a real project:

Use 1ml to build a small binary-classification notebook. Generate 1,000 synthetic rows with scikit-learn's make_classification, 10 features, 5 informative features, class weights [0.8, 0.2] and random_state=42. Reserve a stratified 20% final test set before fitting. Compare a most-frequent dummy baseline with logistic regression in a StandardScaler pipeline using stratified cross-validation on the training portion. Use average precision for ranking and report precision/recall at the default threshold separately. Freeze the approach before the final test. Deliver an executed notebook, a relevant chart and dependency versions. State clearly that the data is synthetic. Do not submit, publish or deploy anything.

This is a starter prompt, not a completed benchmark. The agent may need to install Python packages. Synthetic results do not establish real-world performance.

Check the notebook, not just the answer

  • All cells should run, charts should be visible and conclusions should use measured results.
  • Preprocessing belongs inside each training fold. The final test should not select the model or threshold.
  • The baseline and candidate should use the same evaluation design.
  • The delivered dependencies and files should let you rerun the analysis from the project folder.

If execution fails, ask the agent to reproduce and repair the error. For a larger project, describe what a row means, what you want to predict and when each input is available.
