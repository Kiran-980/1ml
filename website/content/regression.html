Predict a number

Give prediction errors a meaning.

Prices, durations and demand: compare simple baselines, then understand where the model misses.

Start with units and intended use

A price error of 100 means something different from a delivery-time error of 100. Define the target's units and the decisions it informs. Ask whether large errors should carry extra weight and whether over-prediction and under-prediction have different consequences.

Describe the population and period the model will serve. A random sample of past house sales may not support a claim about future prices or a different location.

A prompt to start with

Use 1ml to predict house sale prices from houses.csv. Check target units, missing values, unusual prices and whether location or sale date affects the split. Compare a median-price baseline with a regularized linear model and a justified tree model. Fit preprocessing inside the training folds. Choose the metric before tuning, show large residuals and explain what the final held-out result supports. Deliver an executed notebook and reproducible dependencies.

Make a fair comparison

  • Baseline: a median predictor is a useful reference for absolute error; choose the baseline for the actual metric and setting.
  • Metric: MAE stays in target units and summarizes absolute misses. RMSE gives large errors more influence. Choose according to the problem.
  • Preprocessing: fit imputation, scaling and learned feature transformations inside each training fold.
  • Target transformations: evaluate predictions on the scale needed by the user and document what the transformation changes.

Read the residuals

An average score can conceal systematic errors for expensive houses, sparse locations or a new time period. Inspect predicted versus observed values and residuals across relevant slices. Use training and validation errors to improve the approach, then freeze it before the final test.

Useful output: a baseline comparison in meaningful units, a residual chart, a description of large misses and a clear statement of where the estimate may not generalize.

Start with frame, then use evaluation, train and validate. If the target is a future sequence, read the forecasting guide.
